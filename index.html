¿Qué son los productos notables?

Son patrones de multiplicación y factorización. Las gráficas 3D de esta guía no cambian la matemática: permiten ver mejor las áreas y los volúmenes que forman cada fórmula.

Cómo usar las gráficas: arrastra una figura para rotarla; usa los botones para reiniciar la vista o iniciar/detener el giro automático.

Qué representa cada modelo

  • Cuadrados y rectángulos: el área se divide en partes como a², ab y b².
  • Cubos: el volumen se divide en cubos y prismas como a³, a²b, ab² y b³.
  • Partes rojas: representan cantidades que se restan.

1 y 2. Cuadrados de binomios

Mueve las figuras con el mouse o con el dedo. La parte superior está dividida exactamente según sus áreas.

3. Suma por diferencia

La figura muestra un área grande a² de la que se quita una región b².

Diferencia de cuadrados

(a + b)(a - b) = a² - b²

Área 3D: cuadrado grande menos cuadrado pequeño

Al desarrollar: a² - ab + ab - b². Los términos -ab y +ab se cancelan.

Ejemplo: (x + 5)(x - 5) = x² - 25.

4. Binomios con término común

El rectángulo tiene lados x + a y x + b. Sus cuatro partes son exactamente x², ax, bx y ab.

Rectángulo de áreas

(x + a)(x + b) = x² + (a + b)x + ab

Ejemplo: (x + 2)(x + 7) = x² + 9x + 14.

7 y 8. Suma y diferencia de cubos

Estos modelos muestran una idea geométrica: volúmenes cúbicos que se reorganizan como un binomio por un trinomio.

7. Suma de cubos
